# 小學練功房

小學一年級的數學、注音、時鐘錢幣與國字練習。純靜態網頁，**完全離線可用**，沒有後端、沒有外連資源、沒有任何資料上傳。

**線上版：https://graylightai.github.io/elementary-drill/**

手機用 Safari 或 Chrome 開，「分享 → 加入主畫面」就是全螢幕、鎖直板的 app。

## 數學怎麼教

小孩學加減會經過「全部數 → 接著數 → 推導 → 直接提取」四個階段，前三個都不算會。
所以這裡做了三件事：

- **十格板**：答錯時給的不是文字，是圖。8 個點放上去，剩 2 格空的一眼就看見
- **部分－整體圖**：7 分成 3 和 4。`3+4=7`、`4+3=7`、`7-3=4`、`7-4=3` 是同一件事的四種寫法
- **減法教成「還差多少」**：13-8 不是往回數 8 次，是「8 還差多少到 13」，直接接上湊十

加上反應時間判定（答對但超過 6 秒不升箱），整套都在對付「停不下用數的」這件事。

## 核心：它不隨機出題

一般練習 app 隨機抽題，結果八成時間在練小孩已經會的東西。這裡用間隔重複（Leitner）：

| 情況 | 處理 |
|---|---|
| 答錯 | 掉回第 0 箱，**這一輪稍後再出一次**，今天與明天都還會出現 |
| 答對且夠快（≤ 6 秒） | 升一箱，間隔拉長成 1 → 2 → 4 → 8 → 16 天 |
| **答對但很慢** | **不升箱，明天就回來**——還在扳手指就不是真的會 |

「弱點診斷」頁按細項列出熟練度與反應時間中位數，告訴家長她卡在**哪一個數字、哪一組符號**，而不是只給一個分數。

### 首頁依課綱分類

- 依 108 課綱的學習領域分區：**數學、國語文、英語文、課綱以外**（色彩、邏輯）。
  分區標題底下列出實際涵蓋的課綱類別（例如數學：數與量・空間與形狀・關係・資料與不確定性）
- **年級篩選**：選「二年級」就只出一、二年級學過的內容（複習包含前面的年級）；英文與課綱以外的不分年級。
  年級由每個知識點的課綱代碼推出來：數學 `N-2-13` 是二年級；國語 `Ab-I-1` 是第一學習階段，算一年級起
- 每張卡片標年級範圍（例如「1–3 年級」）；篩選後卡片說明改成實際會出的細項

### 學習地圖

- 首頁的「我的學習地圖」：每個細項（例如「湊十」「7 的乘法」）是一格，**練熟了就點亮**，沒練過的是虛線框
- 進度跟弱點診斷同一個算法（箱號平均），75% 以上點亮；點任何一格就只練那一格
- 一輪結束時，如果有格子是這一輪才點亮的，結算畫面會顯示「🌟 新點亮：湊十」

### 答錯之後

- **往回補基礎**：應用題答錯，下一題先出同一組數字的純算式（例如 7＋8），畫面標「先練基礎」。
  付 10 元的找錢題答錯，先回去練對應的湊十。應用題錯常常不是不會讀題，而是加減事實本身還不熟。
- **講解影片**：有對應影片的知識點（目前是時鐘、加減關係），答錯時多一個「看講解影片」，
  點了在 app 裡用 YouTube 官方嵌入播放器播均一教育平台的影片，關掉就停、回到原題。
  用 `youtube-nocookie.com`、`rel=0`（片尾只推同頻道）。只在有網路時出現。
  均一內容是 CC BY-NC-SA（非商業），**之後若收費要先取得均一同意**。
  對照表在 `src/content/videos.ts`，每支影片都用 YouTube oEmbed 確認過在均一官方頻道、允許嵌入。
  題目裡用到新影片時跑 `python3 scripts/sync-videos.py`：它會找出影片庫還沒有的、逐支確認後補進去
  （不是均一官方頻道或不允許嵌入就停下來）。測試也會擋「用了影片庫裡沒有的影片」。

注音**全部做成視覺題，不需要任何聲音**——這樣離線百分之百可靠，也不依賴裝置有沒有裝中文語音包。

## 開發

需要 Node 22。

```
npm install
npm run dev        # 本機開發，http://localhost:5173（不註冊 Service Worker，改了立刻看到）
npm test           # 題庫安全網，見下
npm run build      # 型別檢查 → 建置到 dist/ → 自動產生 dist/sw.js
npm run preview    # 用建置後的版本測離線
```

推到 `main` 會由 GitHub Actions 跑測試、建置、發佈到 Pages。**測試沒過就不會發佈。**

### 每個知識點都標了課綱代碼

```ts
{ k: 'm.c.7+8', g: '進位加法', subj: 'math', cur: ['N-1-3'], make: () => ({ ... }) }
```

`k` 是學習紀錄的 key，**上線後不能改**，改了那一題的舊進度就消失。
`cur` 對應 `src/content/curriculum.json` 裡的代碼，之後的知識地圖、往回補前置知識都靠它。

### 測試在擋什麼

- 改版前的 1211 個 key 一個都不能少，科目與細項名稱不能變（不然舊進度會掉）
- 每個出題函式跑 30 次：選擇題剛好一個正解、選項不重複
- 數學、注音、國字、時鐘的題目一定要標課綱代碼，而且代碼要真的存在

## 離線

連著網路開一次，Service Worker 會把 140 個檔案（約 1.1 MB，含筆順資料）全部抓進快取。之後從主畫面點開完全不需要網路。

`sw.js` 由 `npm run build` 自動產生，版本字串取自所有檔案內容的雜湊——
以前要手動跑 `build-sw.py`，忘了跑主畫面上的 app 就一直吃舊快取，現在不會了。

## 筆順描字

`public/strokes.json`（435 KB）是從 Make Me a Hanzi 的 `graphics.txt`（30 MB、9574 字）裁出來的
212 個一年級常用字，含每一筆的輪廓路徑與中線。

- 田字格 + 整字淡底，當前筆畫紅色高亮、起筆位置有紅點
- 「看一次怎麼寫」用 SVG mask 沿著筆畫中線把輪廓一點一點露出來
- 手指寫完一筆就比對：重新取樣 16 點算平均距離，另外檢查起筆位置與方向
- 連錯三次自動播一次示範
- 用過示範或錯太多就不算熟，這一題會再回來

**筆順標準的差異：**這份資料沿用中國大陸的筆順規範。絕大多數字跟教育部標準一致，
少數字（例如「方」「出」「比」）順序不同。要對筆順請以學校教的為準，這裡是熟練用的。
app 的「家長須知」裡也寫了這一點。

## 英文：只收初學者程度

單字用**白名單**而不是用字母長度篩。「5 個字母以內」會放進 `boar`、`llama`、
`sloth`、`squid` 這種初學者沒學過的字——字短不等於學過。
現在只留 33 個小一英文課真的會出現的：cat / dog / pig / bird / apple / star …

干擾項也改了：原本「看圖選單字」的干擾是**拼錯的字**（dog / bog / dag / dop），
那是在考拼字錯誤偵測，不是初學者該練的。現在干擾項一律是**別的真單字**。

形近字母（b/d/p/q、m/n、u/v）只用在「字母」類題目的干擾項上，那裡才是對的位置。

## 注音描寫：為什麼不做筆順

Make Me a Hanzi 只收漢字，**37 個注音符號一個都沒有**（已查證），
目前也沒有其他開源的注音筆順資料集。

曾經試過兩條路，都不可靠：

1. **憑記憶手描** — 超過三分之二是錯的（ㄅㄉㄋㄌ 都畫成「刀」、ㄓ 畫成「乙」、
   ㄑㄍ 少筆畫）。已整個丟掉。
2. **從字形自動骨架化推筆畫** — 毛刺與交叉點處理不乾淨，ㄠ 推出 14 筆、ㄕ 推出 1 筆。

所以改成**只做描寫、不做筆順**：

- 字形取自 **Noto Sans TC**（SIL OFL）的真實輪廓，37 個全部正確，不是我畫的
- 她用手指把整個符號描過去，**不要求順序**
- 評分用覆蓋率：把字形切成 48×48 格，`isPointInPath` 問瀏覽器哪些格在字裡面，
  再比對她畫過的格子。覆蓋 ≥70% 且出界 ≤25% 才算過
- 容錯：字形往外膨脹 2 格當容錯帶（手指比筆畫粗）；覆蓋判定也放寬 1 格
  （小孩是沿筆畫中間畫線，不會塗滿）
- 實測 37/37 中線描寫通過，37/37 亂畫被擋下

**要加筆順的話，資料給我就行**：她習字本或《國語注音符號手冊》上的筆順，
我編進去，程式架構已經有了（國字那套就是逐筆的）。

## 眼睛

近距離作業一樣要顧：手機拿在 30 公分左右，設定裡可調休息提醒間隔，到時會跳出 20 秒看遠倒數。
字級以**看得舒服**為準——護眼是靠距離和休息，不是靠把字縮小。
